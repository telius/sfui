# Changelog

## v1.103 (2026-10-16)

### features

- **bronze square minimap theme**: added an option to style the square minimap with authentic camelot heavy bronze aesthetics, featuring burnished bronze borders and sculpted corner brackets while remaining hidden in round mode (`frames/map/square.lua`, `frames/options/tabs/tab_minimap.lua`, `frames/themes/tab_theme.lua`, `frames/themes/engine.lua`, `config.lua`, `common.lua`).
- **action bar quick keybind mode**: added an interactive quick keybinding engine (`frames/actionbars/bind.lua`, `frames/actionbars/bars.lua`, `frames/actionbars/mouseover.lua`, `frames/options/tabs/tab_actionbars.lua`, `sfui.toc`) supporting hover-to-bind across action bars 1-10, the pet bar, and the vehicle leave button, complete with real-time key chord detection, mouse wheel and extra mouse button binding, escape to clear bindings, a movable dialog with character-specific toggle, save and discard buttons, `/kb` slash commands, and seamless integration with blizzard's native quick keybind mode.
- **action bar button lock & shift-to-move**: added a toggle in the action bars options tab to lock action buttons against accidental dragging, enabling movement only while holding the shift key (`frames/actionbars/bars.lua`, `frames/actionbars/actionbars.lua`, `frames/options/tabs/tab_actionbars.lua`, `common.lua`).
- **dynamic minimap dimension controls**: dynamically adapts the minimap configuration tab based on shape selection, displaying independent width and height controls for square minimaps and a single unified diameter scale slider for round minimaps (`frames/options/tabs/tab_minimap.lua`).
- **conjoined ambient weather indicator**: conjoined the weather status indicator to the southeast of the camelot day/night diel frame along the natural curvature of the bronze compass rim (`frames/map/status.lua`).
- **docked mail indicator & options toggle**: added a dedicated toggle in the minimap options tab to dock the mail notification icon directly into the minimap button collection frame by default, cleanly positioning it alongside the clock with automatic width reservation and fallback to the minimap top-left corner when the button collection bar is inactive (`frames/options/tabs/tab_minimap.lua`, `frames/map/indicators.lua`, `frames/map/buttons.lua`, `config.lua`, `common.lua`).
- **radial ring cooldown timers & quest cues**: added live cooldown swipe and countdown timers on radial ring slices matching opie's duration formatting thresholds, quest-starter exclamation overlay badges, quest objective blob gold glow borders, target range checking with red tints, item charge counters, out-of-range/cooldown center status labels, and a toggle for cooldown numbers in the ring options tab (`frames/ring/ring_view.lua`, `frames/ring/ring_live.lua`, `frames/ring/ring.lua`, `frames/ring/providers/ring_questitems.lua`, `frames/options/tabs/tab_ring.lua`).
- **secondary professions in tradeskills ring**: added cooking, first aid, and fishing to the tradeskills & professions radial ring across camelot and modern clients, querying camelot's native 5-slot structure (`p1, p2, cook, fish, faid`) when `sfui.isCamelot` is active, unpacking all profession slots dynamically across clients, resolving abilities via `C_SpellBook.GetSpellBookItemInfo`, and adding fallback detection for known secondary profession spells (`frames/ring/providers/ring_professions.lua`).
- **experience & reputation defaults**: configured reputation tracking to automatically display at max level and dynamically switch to newly gained reputations by default (`config.lua`, `common.lua`, `frames/experience/reputation.lua`).

### improvements & bug fixes

- **camelot minimap optical centering & scaling**: resolved geometry desynchronization where opening the options panel shrank the border and exposed protruding map terrain; restored native container points, applied optical center offsets to compensate for texture asymmetry, tucked the circular aperture flush inside the inner bronze rim, and delegated uniform scaling to blizzard's native edit mode scale pipeline (`frames/map/minimap.lua`, `frames/map/square.lua`, `core/widgets.lua`).
- **action bar default layout & mouseover toggle**: enabled action bars 1 through 6 by default with mouseover fading disabled, and corrected bulk toggle synchronization across all bars (`config.lua`, `common.lua`, `frames/actionbars/actionbars.lua`, `frames/actionbars/mouseover.lua`, `frames/options/tabs/tab_actionbars.lua`).
- **button collection bar positioning**: adjusted default vertical positioning of the minimap button collection bar to 30 to prevent overlapping the compass rim, with automatic database migration for existing profiles (`config.lua`, `common.lua`, `frames/map/buttons.lua`, `frames/options/tabs/tab_minimap.lua`).
- **square minimap pin boundary clipping**: updated minimap canvas pin placement to respect rectangular boundaries when square minimap mode is enabled, preventing corner pin culling (`frames/map/pins.lua`).
- **experience bar tick dividers & challenges**: hidden 20-segment tick dividers and legacy challenges bar by default (`config.lua`, `common.lua`, `frames/experience/bar.lua`, `frames/experience/challenges.lua`).
- **circular ring cooldown swipe**: fit radial ring cooldown swipe textures to the circular icon geometry using blizzard's native circular edge calculation, alpha mask swipe texture, and border insets, preventing square corner clipping past the rounded slice boundary (`core/widgets.lua`, `frames/ring/ring_view.lua`).
- **radial ring combat quest item protection**: eliminated protected function blockage (`UseQuestLogSpecialItem`, `UseItemByName`, and `C_Container.GetItemCooldown` taint) by switching item slices to native macro execution (`/use item:<id>`), returning `false` from pre-click snippets on keydown, deadzone release, and canceled states to abort blizzard click dispatch when no action is selected, configuring `typerelease` alongside `type` for hold-release actions, gating `FireInsecureSlot` so pure secure actions never cross the insecure boundary on release, consolidating item id resolution into a strict validator preventing tracking/spec false matches, unifying range and usability checks across spells and items, adding secret-value protection and combat lockdown guards across `get_slot_cooldown`, `compat.lua`, and `frames/quests/helpers/q_items.lua` on `BAG_UPDATE_COOLDOWN`, bypassing lua arithmetic on secret cooldown durations during combat, removing dynamic override binding churn, adding pre-combat synchronization on PLAYER_REGEN_DISABLED and post-combat button refresh on PLAYER_REGEN_ENABLED, closing font string escape codes in tracking, adding RAID_TARGET_UPDATE listener for world markers, and clearing secure action button attributes on key release (`frames/ring/ring.lua`, `frames/ring/ring_view.lua`, `frames/ring/ring_secure.lua`, `frames/ring/ring_live.lua`, `frames/ring/providers/ring_questitems.lua`, `frames/ring/providers/ring_tracking.lua`, `frames/ring/providers/ring_worldmarkers.lua`, `frames/ring/providers/ring_utility.lua`, `frames/quests/helpers/q_items.lua`, `frames/tracking/trackedicons.lua`, `compat.lua`).
- **action bar shift-drag synchronization**: adopted elvui's modified click architecture by synchronizing `PICKUPACTION` in memory so shift-to-move works reliably when buttons are locked without saving empty character binding sets or clobbering account controls (`frames/actionbars/bars.lua`, `common.lua`, `config.lua`).
- **camelot nameplate soft-target crash guard**: suppressed unhandled soft-target events on blizzard's nameplate driver frame on camelot/classic forever clients to eliminate 1.60.1 client engine crashes when soft-target interact is active (`compat.lua`).
- **documentation & media gallery**: integrated new camelot UI previews across the readme documentation, highlighting the classic dungeon journal, recipe compendium, alt shipping mail dispatcher, pet manager, and real-time memory profiler (`README.md`).
