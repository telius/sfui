# Changelog

## v2.02 (2026-10-15)

### features

- **ring radial menu engine**: added full radial wheel system with secure action execution, controller/keyboard/mouse support, smooth entry/exit animations, and dedicated configuration tab (`frames/ring/ring.lua`, `frames/ring/ring_geometry.lua`, `frames/ring/ring_live.lua`, `frames/ring/ring_secure.lua`, `frames/ring/ring_view.lua`, `frames/options/tabs/tab_ring.lua`).
- **modular ring providers**: integrated built-in rings for player specializations (`frames/ring/providers/ring_specs.lua`), target/world markers (`frames/ring/providers/ring_markers.lua`, `frames/ring/providers/ring_worldmarkers.lua`), professions (`frames/ring/providers/ring_professions.lua`), quest items (`frames/ring/providers/ring_questitems.lua`), tracking options (`frames/ring/providers/ring_tracking.lua`), and utility tools (`frames/ring/providers/ring_utility.lua`).
- **smart quest & inventory radial ring**: expanded quest items ring provider into a full opie-style auto-inventory engine with dynamic bag scanning for active quest objectives (strictly validated against the active quest log), weekly inscription treatises (auto-hidden once completed for the week), usable profession knowledge items, openable reward caches/chests, threshold combination items (e.g. 100 coffer key shards), and uncollected toys, mounts, and pets with automatic key/charm exclusion, category-weighted sorting, and dedicated configuration toggles (`frames/ring/providers/ring_questitems.lua`, `frames/ring/ring.lua`, `frames/options/tabs/tab_ring.lua`).
- **taint-free square minimap**: implemented engine-level square mask (`130937`) with global `GetMinimapShape` hook for community addons, circular clutter suppression without frame hiding, hybrid indoor cave map support, and 1px themed border (`frames/map/square.lua`).
- **customizable minimap dimensions & positioning**: added fine-grained width and height sliders, screen anchor point selection, and offset controls with instant layout recalculation (`frames/map/minimap.lua`, `frames/options/tabs/tab_minimap.lua`).
- **delve & labyrinth boons tracker**: implemented dynamic buff display panel for delve and labyrinth powers (`1280098`), detailing accumulated stacks, abilities, and stat enhancements with automatic sizing below the delve hud and quest tracker (`frames/quests/helpers/q_boons.lua`, `frames/options/tabs/tab_objectives.lua`, `frames/quests/engine/q_layout.lua`, `frames/quests/engine/q_tracker.lua`, `frames/quests/q_mythic.lua`).

### improvements & bug fixes

- **pet bar performance & responsiveness**: decoupled pet bar updates into throttled tick updates (`RequestPetBarUpdate`), dedicated cooldown (`UpdatePetCooldowns`), usability (`UpdatePetUsable`), and hotkey (`UpdatePetHotkeys`) routines with precomputed key caches to prevent combat stutter (`frames/actionbars/bars.lua`).
- **action bar mouseover grid caching**: passed cached configuration blocks during mouseover drag state updates to eliminate redundant database queries across all action slots (`frames/actionbars/mouseover.lua`).
- **portal interaction refinements**: enhanced mouseover responsiveness and backdrop feedback on portal buttons (`frames/portals/portals.lua`).
- **keybinding declarations**: registered ring toggles and radial wheel controls for retail and classic/camelot clients (`Bindings.xml`, `Bindings_Standard.xml`, `Bindings_Camelot.xml`).
- **default vehicle exit button**: liberated blizzard's default `MainMenuBarVehicleLeaveButton` from `MainActionBar`, reparented it to `UIParent`, integrated passenger seat and `VehicleSeatIndicator` visibility detection, and added independent positioning with a dedicated mover in `/sfui unlock` while removing the duplicate exit button from the vehicle action bar (`frames/actionbars/bars.lua`, `frames/actionbars/actionbars.lua`, `frames/actionbars/movers.lua`, `frames/bars/vehicle.lua`, `config.lua`).
- **minimap icon layering & styling**: resolved an issue where minimap addon buttons, LibDBIcon pins, and status indicators were visually occluded or had their textures stripped while mouseover tooltips remained active; removed the opaque center fill from the square minimap backdrop frame, set transparent interior backdrops on square icon styling, hardened icon texture detection for numeric FileDataIDs, and locked frame strata and levels to guarantee button visibility above the map canvas (`core/widgets.lua`, `frames/map/square.lua`, `frames/map/minimap.lua`).
- **minimap mail & dungeon finder indicators**: resolved an issue where the mail indicator frame was occluded behind the square minimap canvas and the dungeon finder (queue status) eye was suppressed alongside the hidden micro menu in retail; reparented and anchored the queue status button cleanly at the bottom-left corner of the minimap, and pinned the mail indicator frame to the top-right corner of the minimap with elevated medium strata and level locking (`frames/actionbars/actionbars.lua`, `frames/map/minimap.lua`, `frames/map/square.lua`).
- **item comparison & tooltip safety**: corrected tooltip comparison hook dispatchers for modern clients, whitelisted comparison tooltips to prevent third-party inspection scanner crashes, and enabled auto-comparison integration for equippable items in the loot feed (`frames/gear/compare.lua`, `frames/gear/lootfeed.lua`).
- **druid travel form action bar paging**: resolved an issue where retail druid travel form incorrectly paged action bar 1 to cat form due to unconstrained classic stance fallbacks, ensuring travel form remains on the primary bar (page 1) and correctly prioritizes skyriding (page 11) in flight form (`frames/actionbars/paging.lua`).
- **custom ring toy support & execution**: resolved an issue where dragging toys from the toy box, bags, or action bars into custom utility ring slots either failed to drop, was mistakenly stored as perishable inventory items, or failed to cast due to missing bag possession; added automatic toy identification across cursor types, seamless toy promotion, secure action execution via `SECURE_ACTIONS.toy` with `/use item:id` macro fallback, toy box tooltip inspection, and radial cooldown overlays (`common.lua`, `frames/options/tabs/tab_ring.lua`, `frames/ring/providers/ring_utility.lua`, `frames/ring/ring_view.lua`, `frames/ring/ring_secure.lua`).
